# TalkingPete: Virtual Pet Simulation (WinForms)

Курсовой проект по дисциплине «Объектно-ориентированное программирование». Представляет собой интерактивную среду взаимодействия с персонажем, включающую систему состояний, менеджмент ресурсов и набор встроенных мини-игр.

## Технический стек
* **Язык разработки:** C# 12
* **Платформа:** .NET 8.0 (Windows Forms)
* **Графический движок:** GDI+ (динамическая отрисовка интерфейса через переопределение метода `OnPaint`)
* **Архитектура:** Событийно-ориентированная модель управления состояниями (State Machine на базе Enum)

## Ключевые особенности реализации

### Игровые механики
* **Менеджмент ресурсов:** Реализована логика изменения характеристик (Энергия, Опыт, Настроение) в реальном времени с использованием системных таймеров.
* **Система прогрессии:** Уровневая система (Level-up), где каждый новый уровень масштабирует максимальные показатели персонажа.
* **Интерактивность:** Обработка событий мыши (расчет координат для взаимодействия с объектами интерьера) и ввод с клавиатуры для управления в мини-играх.

### Встроенные модули (Мини-игры)
1. **Cooking Game:** Логическая игра на запоминание и воспроизведение последовательностей.
2. **Memory Game:** Реализация классического алгоритма «Simon Says» для проверки памяти.
3. **Catch Game:** Аркадный модуль с процедурной генерацией падающих объектов и обработкой коллизий.

## Технические решения
* **GfxExt:** Разработан кастомный класс расширений для `System.Drawing.Graphics`, позволяющий отрисовывать сложные элементы интерфейса (скругленные прямоугольники) через `GraphicsPath`.
* **Оптимизация рендеринга:** Применение метода `Invalidate()` для точечной перерисовки кадров, что минимизирует мерцание и нагрузку на систему.
* **Управление состояниями:** Использование перечислений `PetState`, `Room` и `GameState` для обеспечения предсказуемых переходов между игровыми экранами.

## Инструкция по запуску

### Требования
* Наличие установленного .NET 8.0 SDK.
* Среда разработки Visual Studio 2022 или VS Code.
